# Cloud Security Quest

Interactive cloud security game focused on:

- Microsoft Security
- AWS Security
- GCP Security
- SOC Operations
- Incident Response
- Identity Protection
- DevSecOps

Players enter simulated security incidents and make decisions in real time to discover their cloud security profile.

## Features

- Interactive security scenarios
- Animated cyber interface
- Cloud security decision engine
- LinkedIn share integration
- Multi-cloud concepts
- Security profile card generation

## Technologies

- HTML5
- CSS3
- JavaScript
